A dog explains why the homework got eaten: it smelled like the pencil its owner chews when stuck — so the dog was helping, and regrets nothing.

## Run it

```bash
python3 main.py
```

For local testing, set `OUTPUT_DIR` to choose where the entry is written (defaults to `/output`):

```bash
OUTPUT_DIR=./output python3 main.py
```

This writes one line — the dog's excuse — to `/output/entry.txt`, byte-identical on every run.
